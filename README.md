# StockPred Pro — Quantitative Financial Intelligence Platform

AI-driven quantitative stock market analysis, price forecasting (TCN, DQL, XGBoost, Kalman), macro news sentiment analysis, and interactive financial dashboard.

## Tech Stack
- **Backend**: FastAPI, PyJWT, yfinance, scikit-learn, VADER Sentiment
- **Frontend**: React (Vite, TypeScript, TailwindCSS, Lucide Icons)

## Features
- Real-time US & Indian market ticker tracking
- Machine learning Ensemble price predictions
- Macro catalyst scanning & sentiment scoring
- Financial status & valuation metrics analysis
